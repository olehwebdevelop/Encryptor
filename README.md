# Encryptor Tool

Modern browser-based encryption tool built with JavaScript featuring real-time text encryption and decryption in a clean responsive interface.

## Features

- Text encryption and decryption
- Real-time text transformation
- Responsive minimalist UI
- Fast client-side processing
- Lightweight implementation
- Smooth user interactions
- Instant encrypted/decrypted output

## Technologies

- HTML5
- CSS3
- JavaScript

## Functionality

- Encrypts user-entered text
- Decrypts encrypted text back to readable format
- Processes all data directly in the browser
- Real-time updates without page reload
- No backend or external libraries required

## Goals

This project was created to improve JavaScript logic handling, string manipulation, and interactive frontend development while building a functional encryption/decryption utility.
